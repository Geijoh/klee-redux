The visual language of UE5 graph editors

A breakdown of the Blueprint and Material node systems — node anatomy, role and type color semantics, wires, feedback states, and canvas conventions. Values are engine defaults.

01

Scope & method

This document covers the two most-used node graphs in Unreal Engine: the Blueprint event graph and the Material expression graph. Both are built on the same Slate graph framework — one canvas, one typeface, one settings object — then diverge sharply in how they spend color.

Color tokens live as linear-space FLinearColor values in UGraphEditorSettings; hex values here are those defaults converted to sRGB. Values that come from Slate style brushes rather than settings tokens are sampled from the rendered UI and marked ≈.

Canvas & grid

Both editors share one canvas: a mid-dark neutral field ruled by a two-level grid. Grid lines are darker than the field, not lighter — the grid reads as grooves, keeping nodes the brightest surfaces on screen. The grid fades as you zoom away.

Nodes snap to the 16 px minor grid when dragged. Panning is unbounded; there is no page or artboard concept. Watermarks (graph type, zoom level) render as huge low-contrast type pinned to the viewport corners.

03

Typography & density

The editor sets one family — Roboto, Slate’s default UI face. Hierarchy inside a node is carried by weight, size, and opacity, never by hue. Every title carries a 1 px black drop shadow so white text survives any header tint.

Density is managed by zoom level-of-detail: zooming out first drops default-value widgets, then pin labels, then pins — at the lowest LOD a node is just a tinted title bar. Long labels wrap their value widgets onto the next line; rarely-used pins collapse behind a chevron expander at the node’s foot.

Blueprint node anatomy

A standard node is a near-black rounded card (≈8 px radius, ≈1 px gray border, soft drop shadow) under a tinted title gradient that runs bright-left to dark-right. Inputs stack on the left, outputs on the right; execution pins always take the first row. Unconnected inputs surface default-value widgets inline.

Special forms drop the standard chrome: variable getters are type-tinted capsules with a single output; compact math nodes trade their title bar for a large faded glyph; latent (time-consuming) calls wear a clock badge overlapping the top-right corner; events surface their bindable delegate as a red square in the title bar. Checked booleans render a white tick; color-type pins expose a swatch chip; nodes with advanced pins end in a centered expander triangle.

Containers keep their element’s tint — an array of vectors is a gold nine-square grid. Map pins show two colors at once: key shape + value shape. In UE5, Blueprint floats are double-precision but keep the lime float tint; the darker double green appears on natively-typed C++ pins.

07

Wires & routing

Wires are cubic Béziers with horizontal tangents, tinted by their output pin. Execution wires are white and thicker — 2.5 px vs 1.5 px for data (both defaults). Hovering a wire brightens and thickens it; double-clicking inserts a reroute knot; dragging off a pin shows a ghost wire with a “Place a new node” prompt. During play-in-editor debugging, recently executed exec wires tint hot tan-orange and run traveling bubbles along the path, then decay.

08

Selection & feedback states

State never repaints the node — it wraps it. Selection adds an amber outline and glow; compile problems attach full-width banners to the node’s foot; breakpoints badge the corner; disabled or unreached nodes dim in place. When execution halts at a breakpoint, a large red arrow drops onto the node from above; watched values pin small “Watching …” bubbles to their node.

09

Comments & organization

Comment boxes are the only user-tintable surface: an opaque title bar over a translucent body that groups and moves nodes together. Default tint is white (DefaultCommentNodeTitleColor 1,1,1); teams recolor them freely. At low zoom the title re-renders as a fixed-size bubble so it stays legible. Individual nodes can also carry a small white bubble note above their header.

10

The Material graph system

RULE
Materials invert the system: with no execution model there is no role axis, so the header tint encodes the expression’s output type — and pins go uniform.

The Material editor reuses the Blueprint pin palette, but moves it up to the title bar: a scalar constant and a Scalar Parameter both wear float lime; vector constants and parameters wear gold; texture and object references wear the object blue. Everything else stays neutral gray. Data pins themselves are a uniform pale circle — type mismatches surface at compile, not at the pin.

Density devices are Materials-specific: expressions preview their result live inside the node; constants print their value as the title; the most common expressions place with single-key shortcuts (1–4 for constants, T texture, S/V parameters, M multiply, A add, L lerp). On the result node, inputs unusable under the current Blend Mode / Shading Model gray out. The node being previewed gets a blue border — FColor(70,100,200).

Appendix — sources & conversion

TOKENSPin and title colors are UGraphEditorSettings defaults — user-editable under Editor Preferences → Graph Editors, persisted to [/Script/GraphEditor.GraphEditorSettings] in EditorPerProjectUserSettings.ini. Everything shown here is the out-of-box default.
CONVERSIONTokens are linear-space floats; screens are sRGB. Hex values use the standard transfer function srgb = 1.055·lin1/2.4 − 0.055 (lin > 0.0031308), rounded per channel.
MATERIALSMaterial header routing is from UMaterialGraphNode::GetNodeTitleColor(): bool → BooleanPinTypeColor, scalar → FloatPinTypeColor, vector → VectorPinTypeColor, object → ObjectPinTypeColor, function calls → FunctionCallNodeTitleColor, outputs → ResultNodeTitleColor.
≈ VALUESCanvas grays, node body/border, selection amber, cast teal, channel-split pin tints, and LOD thresholds come from Slate style brushes, not settings tokens — they are sampled approximations and can shift between engine versions.
